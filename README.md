# LowLevel Labs website

Source for [lowlevellabs.in](https://lowlevellabs.in), a static site served by GitHub Pages.
Articles cover embedded firmware, Linux device drivers, C, assembly, CPU internals, RTOS and VxWorks.

## How the site is built

Pages are generated by a small Python script (standard library only) so every page shares
one header, footer and layout.

```
content/articles/<slug>.html   article bodies (edit these)
content/pages/<name>.html      about, contact, projects (edit these)
tools/build.py                 the generator: topics, templates, sitemap
styles.css, script.js          design system and site behaviour
articles/, topics/, *.html     GENERATED output, committed for GitHub Pages
```

After any change to `content/` or `tools/build.py`, run:

```bash
python3 tools/build.py
```

and commit both the source and the generated files. Don't edit generated HTML by hand;
it is overwritten on the next build.

## Writing an article

Create `content/articles/my-topic.html`:

```html
<!--meta
title: Article title
description: One sentence for search results and listings.
topic: drivers          # boot | firmware | c | asm | cpu | rtos | drivers | linux
date: 2026-11-20
read: 8 min read
order: 20               # optional: position within its topic (lower first)
featured: 1             # optional: show in "Start here" on the home page
lede: The opening paragraph shown under the title.
-->
<h2>First section</h2>
<p>Text…</p>
```

Inside the body you can use:

- Fenced code blocks: a line with three backticks and a language (`c`, `armasm`, `x86asm`,
  `bash`, `makefile`, `dts`, `ld`), the code, then three backticks. Code is escaped for you.
- Figures: `<figure class="fig"><svg class="dg" …>…</svg><figcaption>…</figcaption></figure>`.
  Diagram classes (`b`, `ink`, `cu`, `sg`, `wn`, `ln`, `lc`, `ls`, `s`, `m`, `h`) follow the
  site palette and switch automatically in dark mode. Figures are numbered automatically.
- Callouts: `<div class="note">`, `<div class="pitfall">`, `<div class="key">`, each starting
  with a `<strong>` title.

Every `<h2>` becomes an entry in the article's "On this page" sidebar.

## Preview locally

```bash
python3 tools/build.py
python3 -m http.server 8000
```

Then open http://localhost:8000.

## Deployment

GitHub Pages serves the `main` branch root. `CNAME` holds the custom domain and `.nojekyll`
disables Jekyll processing.
